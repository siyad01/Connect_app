# Connect

🚀 **Connect** is a professional networking web application built using the **MERN stack** (MongoDB, Express, React, Node.js). It enables users to create profiles, build connections, share posts, and engage in real-time messaging, similar to LinkedIn.

## 🌟 Features

- **User Authentication** (Register/Login)
- **Profile Management** (Edit profile, add skills, experience, and education)
- **Connections** (Send/Accept/Reject connection requests)
- **Posts & Engagement** (Create posts, like, comment, and share)
- **Real-time Messaging** (One-on-one chat system)
- **Search & Discover** (Find professionals and expand networks)
- **Responsive UI** (Optimized for mobile & desktop)

## 🛠️ Tech Stack

- **Frontend:** React, Tailwind CSS
- **Backend:** Node.js, Express.js
- **Database:** MongoDB, Mongoose
- **Authentication:** JWT (JSON Web Token)
- **Real-time Communication:** Socket.io
- **Storage:** Cloudinary (for media uploads)

## 🚀 Installation & Setup

1. **Clone the repository**
   ```bash
   git clone https://github.com/siyad01/connect_app.git
   cd connect
   ```

2. **Set up the backend**
   ```bash
   cd backend
   npm install
   npm start
   ```

3. **Set up the frontend**
   ```bash
   cd frontend
   npm install
   npm run dev
   ```

4. **Environment Variables:** Create a `.env` file in the backend with:
   ```env
   MONGO_URI=your_mongodb_connection_string
   JWT_SECRET=your_secret_key
   CLOUDINARY_URL=your_cloudinary_url
   ```
